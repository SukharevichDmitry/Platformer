# Варианты начала

Планируется десять авторских начал. Выбор может быть случайным среди уже
доступных вариантов либо предоставляться игроку после первого прохождения.
Это решение будет принято вместе с метапрогрессией.

Во всех вариантах:

- герой — молодой житель руин без особой крови и предназначения;
- начальный дом расположен у границы или узла влияния фракций;
- личное событие заставляет героя покинуть привычную жизнь;
- родственники и близкие могут поддерживать разные стороны конфликта;
- старт меняет ранних NPC, первые улики и отношение к фракциям, но не факты
  прошлого города;
- первая цель конкретна и лична, а общегородской конфликт открывается позже.
